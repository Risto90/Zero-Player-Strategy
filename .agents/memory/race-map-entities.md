---
name: Race map entities
description: User-facing terminology and map-list behavior for the population race categories.
---

Use «расы» for these categories in the interface. The race map list must behave like the ethnicity and religion lists: include only races with population on the map, allow selecting a race-specific map layer, and link each row to a race profile.

**Why:** the user explicitly corrected the term «происхождение» and rejected a static category list without entity pages or map-presence filtering.

**How to apply:** Preserve the term, live-population filtering, map-layer selection, and profile navigation in future UI changes for these categories.
