---
name: Пауза сеанса задачи
description: Различие между состоянием проектной задачи и состоянием сеанса Replit Agent.
---

Индикатор «Задача на паузе» относится к рабочему сеансу Replit Agent и может появляться, даже когда запись проектной задачи показывает `IN_PROGRESS` без блокировки. Проверяй оба состояния; не объявляй сеанс активным только по статусу записи задачи. Чтобы продолжить, пользователь должен описать задачу в новом сеансе Agent.

**Почему:** скриншот пользователя показал паузу сеанса, пока API проектных задач возвращал активный статус.

**Как применять:** при расхождении объясни разницу между сеансом и записью задачи, повторно проверь статус после запроса пользователя на продолжение и не отправляй промежуточный финальный ответ, если он снова поставит сеанс на паузу.
