---
name: Existing project tasks
description: Honor the user's request to work on an existing task rather than creating a duplicate.
---

When the user identifies an existing project task, continue or update that task instead of creating a replacement task.

**Why:** The user said they cannot edit the task list themselves and explicitly asked that existing work be restored rather than duplicated.

**How to apply:** In Build mode, work on the exact existing task the user names. Do not create a substitute task.
