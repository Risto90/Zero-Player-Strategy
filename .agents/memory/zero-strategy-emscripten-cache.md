---
name: Изменяемый кэш Emscripten
description: Сборка Emscripten из Nix требует изменяемого рабочего кэша вне каталога компилятора.
---

Если Emscripten установлен из Nix, каталог пакета и его готовые заголовки доступны только для чтения. `EM_CACHE` нужно направить в игнорируемый каталог сборки и при первом запуске скопировать кэш от той же версии Emscripten с правом записи: компилятор дополняет sysroot несколькими перекрывающимися наборами заголовков и собирает библиотеки.

**Почему:** повторные попытки с пустым кэшем в каталоге Nix и в обычном пользовательском каталоге завершались на неизменяемых правах sysroot.

**Как применять:** при настройке новых WASM-сборок в Replit сначала задавать изменяемый `EM_CACHE`, затем запускать именно закреплённую версию Emscripten и хранить результаты/кэш вне Git и публикации.
