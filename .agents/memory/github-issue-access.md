---
name: Доступ к GitHub Issues
description: Ограничение подключения агента и проверенный альтернативный канал публикации задач.
---

Авторизованное подключение GitHub может сообщать исправное состояние и разрешение repo, но не предоставлять соединение текущему сеансу агента. Это не доказывает отсутствие прав владельца репозитория и не исправляется гарантированно переподключением.

**Почему:** пользователь сообщил, что повторное отключение прав в Replit и GitHub не помогло; проверка показала, что отправка Git-коммита через существующий origin и создание Issue обработчиком GitHub Actions работают.

**Как применять:** при таком ограничении не просить токены и не утверждать, что у пользователя нет прав. С разрешения пользователя можно передать описание задачи коммитом в отдельную ветку и создать Issue через Actions с issues:write. Подтверждать результат фактическим Issue и завершением запуска, а не одним успешным push. Этот путь не предоставляет агенту прямой доступ к произвольным операциям API.
