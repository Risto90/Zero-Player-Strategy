---
name: Chronicle importance
description: User-defined rules for highlighting events in the game history.
---

Only event types explicitly named by the user or design document should be marked important. Routine expansion by states or nomads is not important; keep the existing history classification aligned when loading old saves.

**Why:** The user explicitly said the event list was already provided and objected to invented importance; expansion is the most frequent map event.

**How to apply:** Leave unconfirmed event types unmarked. Preserve user-provided event lists and clarification answers verbatim in the project record; do not replace them with a summary. When changing chronicle tagging, preserve the specified set and demote routine expansion in existing records.
