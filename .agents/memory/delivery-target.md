---
name: Браузерная реализация
description: Поддерживаемая версия Zero Strategy работает только в браузере; мобильные реализации исключены.
---
У Zero Strategy только браузерная версия; на телефоне используется тот же браузерный интерфейс, нативного приложения нет. В опубликованной версии игра должна открываться прямо в браузере. Expo остаётся инструментом разработки и сборки веб-версии. Для загрузки файлов и других возможностей используйте браузерные API, не добавляя нативные модули обмена и выбора файлов.

**Why:** 28 октября 2026 года пользователь уточнил, что приложение работает только в браузере и не собирается для Expo Go на Android.

**How to apply:** сохранять браузерный интерфейс и веб-сборку Expo. Устанавливать только зависимости, нужные браузерному приложению; не обновлять пакеты ради Expo Go и не ставить диагностические инструменты только для проверки агента. Для скачивания и других действий в браузере использовать браузерные API.
