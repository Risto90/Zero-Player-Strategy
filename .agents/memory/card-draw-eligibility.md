---
name: Доступность и вероятность карт
description: Отделяет детерминированную возможность карты от её вероятностного веса.
---
Доступность карты определяется только детерминированными условиями мира, а не результатом случайной генерации. Любой положительный вес оставляет карту в распределении розыгрыша: его малость уменьшает шанс, но не делает карту недоступной.

**Почему:** пользователь прямо указал это правило после того, как предварительная генерация с фиксированным начальным числом ошибочно исключала карты по результату случайного прогона.

**Как применять:** проверять доступность отдельными детерминированными условиями; затем выбирать карту по её весу и запускать генератор только для выбранного варианта. Не использовать случайный тестовый прогон как фильтр доступности и никогда не перерозыгрывать выбранную карту при неудаче генератора: учесть детерминированную вероятность результата в весе либо исключить вариант до выбора.

После розыгрыша каждая карта с нормированной вероятностью выше выбранной получает адаптивный множитель ×1,1. Он накапливается при каждом таком пропуске (×1,1, ×1,21, ×1,331 и далее) и сбрасывается к ×1, когда карта выпадает.

**Почему:** пользователь уточнил, что накопительное повышение вероятности после пропусков является частью розыгрыша и должно учитываться в базовом шансе.

**Как применять:** сохранять этот множитель в базовых шансах при сравнении периодов без модификаторов формы правления и не выводить его как отдельный модификатор.

Если для карты не указан процентный шанс, её базовый вес равен 1. Качественные слова вроде «редко» или «обычно» сами по себе не дают числового множителя.

В игре существуют только два пула карт: мировой и страновой. Не вводить отдельные классы «личных карт» или «событий жизни» и не добавлять карты, чьи правила ещё не описаны. Страновые карты персонажей группируются по виду события: общий вес — сумма индивидуальных вкладов, а цель после розыгрыша выбирается пропорционально эффективным шансам. Каждый персонаж сохраняет свой накопительный множитель; его ключ может содержать ID персонажа, но не ID пары. Для брака кандидаты выбираются после розыгрыша карты, а не задают отдельный шанс пары. Смерть от старости и случайная смерть остаются разными видами страновых карт, с суммированием индивидуальных весов по живым персонажам страны.

**Почему:** пользователь прямо уточнил, что существуют только мировые и страновые карты; группировка по виду события допустима лишь при сохранении индивидуальных шансов и накопления, без карт на пары.

**Почему:** пользователь прямо уточнил, что существуют только мировой и страновой пулы, группировка по виду события должна сохранять индивидуальные шансы, а неописанные варианты не должны попадать в розыгрыш до появления правил.

**Как применять:** держать одну запись в розыгрыше на описанный вид события, обновлять накопительный множитель каждого персонажа по его индивидуальной вероятности, а после розыгрыша выбирать цель пропорционально индивидуальному весу. Не создавать парные ключи; для брака сохранять выбор двух кандидатов. Пул отслеживаемых персонажей для семейных событий брать из правил формы правления. Риски смерти, заданные на весь возрастной период, переводить в годовые так, чтобы суммарная вероятность за весь период совпадала с исходной. Не вводить численные коэффициенты для качественных описаний без отдельного правила в дизайн-доке.
