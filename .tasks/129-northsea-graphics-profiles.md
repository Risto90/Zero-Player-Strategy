## Что и зачем
Воспроизвести правила профилей графики NorthSea для Zero Strategy: WebGPU — общий основной API, Vulkan — только нативный профиль, WebGL — браузерный резерв.

## Точный алгоритм участка
На Android/Linux определять точную модель GPU. В автоматическом режиме прямо Vulkan выбирать только для AMD Radeon RX 400, RX 500, RX Vega 56 и RX Vega 64. На остальных GPU использовать WebGPU, если он доступен; нативный Vulkan — только если WebGPU недоступен и Vulkan доступен. Не выводить приоритет только из производителя или наличия драйвера.
В браузере автоматический порядок — WebGPU, затем WebGL. Для сохранённого принудительного выбора не переключать API без согласия пользователя. Предусмотреть понятную ошибку, если выбранный или доступный профиль не может инициализироваться.
Общие меши, контуры, игровые правила и ресурсы остаются едиными для профилей; не создавать отдельную игровую логику для Vulkan или WebGL.

## Готово, когда
- Автоматический и принудительный выбор соответствует точным правилам NorthSea и сохраняется между запусками.
- В браузере доступны WebGPU и WebGL, в нативных сборках — WebGPU и Vulkan.
- Тестами покрыты доступность/недоступность API, указанные модели GPU и отсутствие незаметного переключения.
