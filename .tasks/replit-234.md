## Что и зачем
Перенести пользовательские экраны и жизненный цикл приложения с Expo/React Native на общий R + Rust runtime; браузерная версия остаётся полноценной и не требует Node.js.

## Точный алгоритм участка
Браузерный пакет запускается как статический HTML/CSS/SVG shell с WebR и Rust/WASM модулями. Вызовы между ними проходят только по контракту задачи #231; ручные JavaScript/TypeScript игровые модули и Node runtime не добавляются. Разрешены только автоматически сгенерированные инструменты сборки.
Нативные Android/Linux приложения запускают тот же мир и игровые правила без Expo/Metro. Хранение, маршруты и состояние UI не должны создавать отдельную реализацию игры. Сохранять существующие визуальные функции, ввод и переходы, сверяя их экранными и поведенческими тестами до удаления старых экранов.

## Готово, когда
- В браузере R-пакет запускается через WebR, а общий Rust/WASM код обслуживает игровые действия и рендеринг.
- Android и Linux запускаются нативно, без Expo/Metro и без Node.js runtime.
- Все действующие экраны и пользовательские действия доступны и проверены на целевых платформах.
