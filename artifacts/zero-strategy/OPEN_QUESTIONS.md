# Открытые вопросы по стилям флагов

## Сопоставление игровых культур с профилями

Техническое задание не задаёт соответствие искусственных культур Zero Strategy
профилям «эпоха × культурный круг» и не определяет перевод черт культуры в теги.
По умолчанию новые культуры получают стабильный профиль из одинаково взвешенного
набора профилей настроенной эпохи; явные соответствия культуры профилю и тегам
задаются в `flagIdentityConfig.ts`. Пока профиль не настроен, черты персонажей
не трактуются как культурные теги.

## Эпоха для новых сущностей

В игровом времени нет заданного соответствия эпохам генератора. По умолчанию
конфигурация использует эпоху 6 для новых флагов, религиозных символов, городских
гербов и культурных стилей. Это заменяемая настройка, а не вывод об историческом
происхождении игрового народа.

## Источник родства религий

Правила не указывают, откуда должна происходить стилевая основа новой религии.
По умолчанию источник родства отключён (`religionParentSource: 'none'`).
Настройка `current-country` наследует стиль текущей религии страны, когда новая
вера возникает в карточке страны. Глобальная карточка веры остаётся отдельной
ветвью, пока для неё не задано другое правило.
