# Контракт вычислительного ядра Zero Strategy — ABI 1

## Назначение и границы

Ядро предоставляет детерминированные математические примитивы и управление двоичной памятью. Оно не принимает игровые решения и не задаёт правила населения, карт, кистей или транзакций игры. Потребители передают типизированные буферы и идентификаторы; сериализация всей карты в JSON для каждого вызова запрещена.

Реальные точки интеграции в текущей игре:

| Потребитель | Данные игры | Граница будущей интеграции |
| --- | --- | --- |
| `game/contours.ts` | Контурные строки `{y,start,end}`, их пересечения, объединение и вычитание | Интервалы целых координат; геометрические операции не разворачивают область в список пикселей |
| `game/zones.ts` | Закрытые кольца в координатах вершин и скалярные зоны | Типизированные значения растра, маска включения, кольца; обход по строкам может уступать интерфейсу управления |
| `game/composition.ts` | Идентификаторы групп и доли кратные `SHARE_STEP` | Массивы идентификаторов и весов; игровые правила округления остаются у игры |
| `game/brush.ts`, `game/countryExpansionContours.ts` | Выбор и пересечение участков карты | Наборы/контуры; ограничения доступной, начальной и конечной области не смешиваются |
| `game/mapLabels.ts` | Поиск позиций по видимому контуру | Геометрические запросы и камера остаются вне универсального математического ядра |

Текущая реализация ABI 1 включает реестр буферов, сложение `int32` и суммирование `int32` в `int64`. Остальные операции ниже определяют расширяемый контракт для следующих модулей; их реализация не подразумевается этой версией.

## Общие правила вызова

- Версия ABI — `1`; несовпадение major-версии завершает загрузку явной ошибкой.
- Функции C ABI возвращают общий код `zk_error`. При ошибке выходные значения не меняются.
- `0` зарезервирован как недопустимый дескриптор. Остальные дескрипторы имеют вид `(поколение:uint32 << 32) | (слот:uint32 + 1)`.
- Дескриптор принадлежит экземпляру ядра, который его выдал. Освобождение делает его недействительным; повторное освобождение сообщает устаревший дескриптор. Слот с исчерпанными поколениями выводится из оборота, поколения не переиспользуются.
- Адрес буфера остаётся действителен до `zk_buffer_release`. Нельзя освобождать/переиспользовать буфер одновременно с обращением к его представлению. Размер буфера неизменен.
- На WASM адрес — смещение в линейной памяти, на нативной платформе — адрес процесса. После роста памяти WASM старые `TypedArray`-представления считаются недействительными; представление нужно получить повторно.
- Совокупный объём буферов одного экземпляра ограничен 256 МиБ; одновременно допускается не более 65 536 дескрипторов. Переполнение лимита и системная нехватка памяти различаются кодами ошибок.
- Режим выполнения считывается из скомпилированного артефакта. Однопоточная сборка никогда не сообщает о поддержке потоков; запрос потоков для неё отклоняется.
- Пустой вход допустим там, где ниже не указано иное. Пустые буферы имеют валидный дескриптор; указатель может быть нулевым, длина — нулевой.
- Порядок байт пакетов — little-endian. Целые числа имеют фиксированную ширину; числа с плавающей точкой — IEEE 754 binary32/binary64. NaN и бесконечность запрещены в геометрических и численных операциях.
- Целочисленные переполнения дают `OVERFLOW`, без насыщения и без циклического перехода. Для повторяемости запрещены `fast-math` и неявное изменение порядка суммирования.
- Результат с плавающей точкой сравнивают с абсолютным допуском `1e-9` плюс относительный допуск `1e-9 × max(|a|,|b|)`, если операция не устанавливает более строгую точность.
- Сортировка равных ключей стабильна; при равных остатках или расстояниях используется возрастающий числовой идентификатор. Игровая семантика квантования не переносится в ядро без отдельной версии контракта.

## Коды ошибок

| Код | Значение и условие |
| --- | --- |
| Число | Код | Значение и условие |
| ---: | --- | --- |
| 0 | `OK` | Операция завершена |
| 1 | `INVALID_ARGUMENT` | Нулевой обязательный указатель, неизвестный тип или некорректное значение |
| 2 | `OUT_OF_MEMORY` | Не удалось выделить память или достигнут совокупный лимит |
| 3 | `INVALID_HANDLE` | Нулевой или структурно недопустимый дескриптор |
| 4 | `STALE_HANDLE` | Дескриптор уже освобождён или поколение не совпало |
| 5 | `TYPE_MISMATCH` | Дескриптор имеет тип, не поддерживаемый операцией |
| 6 | `OUT_OF_RANGE` | Диапазон, индекс, размер или координата вне разрешённых границ |
| 7 | `OVERFLOW` | Точный целочисленный результат не помещается в целевой тип |
| 8 | `UNSUPPORTED` | Запрошенный режим или возможности платформы недоступны |
| 9 | `CONFLICT` | Ожидаемая ревизия транзакции не совпала с текущей |
| 10 | `INTERNAL` | Нарушен внутренний инвариант; вызывающая сторона не должна продолжать транзакцию |

## Каталог операций и численная семантика

Все типы ниже используют общий `zk_error`; операции, для которых не задан код, возвращают только перечисленные в контракте для их класса.

| Семейство | Вход | Результат | Пустые и вырожденные данные | Ошибки и точность |
| --- | --- | --- | --- | --- |
| Буферы | Тип из `u8/u16/i32/u32/f32/f64/i64/u64`, число элементов `uint32` | Дескриптор поколения, длина байт, адрес типизированной памяти | Ноль элементов создаёт пустой живой буфер; нулевой адрес допустим только при нулевой длине | Неизвестный тип — `INVALID_ARGUMENT`, превышение размера — `OUT_OF_RANGE`, лимита/памяти/дескрипторов — `OUT_OF_MEMORY`, старый дескриптор — `STALE_HANDLE` |
| Множества целых | Отсортированные по возрастанию массивы `uint32`, без повторов; `union`, `intersection`, `difference` | Новый отсортированный массив без повторов | Пустое объединение даёт пустое множество; пересечение с пустым — пустое; вычитание пустого не меняет левое множество | Нарушение канонической формы — `INVALID_ARGUMENT`; размер результата — до объединённой длины с проверкой переполнения; точное целочисленное сравнение |
| Взвешенные группы | Пары `groupId:uint32`, `weight:uint64`; уникальные ID; веса неотрицательны | Нормализованный/суммированный набор групп согласно параметру операции | Пустой набор имеет сумму 0; нулевая сумма не превращается в равное распределение; нулевые веса опускаются только если это указано операцией | Повтор ID обрабатывается только явно указанным режимом; суммирование `uint64` обнаруживает переполнение; вероятностные величины — `f64` с общим допуском |
| Контуры областей | Интервалы полуоткрытого вида `[start,end)` на целочисленной строке либо кольца вершин по пиксельным границам | Канонические объединённые интервалы или кольца с неявным замыканием | Пустой контур допустим; нулевая ширина/высота отбрасывается; касание по границе не создаёт общей площади | Непростые кольца/неверные границы — `INVALID_ARGUMENT`; координаты вне размерности — `OUT_OF_RANGE`; интервалы обрабатываются точно целыми |
| Векторы | Компоненты `f64`, одинаковая конечная размерность | Сложение, вычитание, скалярное произведение, норма или расстояние | Размерность 0 даёт нулевую норму и расстояние; несовпадающая размерность — ошибка | NaN/∞ — `INVALID_ARGUMENT`; промежуточная/выходная нечисловая величина — `OVERFLOW`; допуск `1e-9` |
| Дуги | Конечные центр, радиус `r≥0`, начало и знаковый размах в радианах | Точки/длина дуги/проверка принадлежности согласно операции | `r=0` даёт точку и нулевую длину; нулевой размах — пустая дуга; полный оборот не заменяется нулём | Неположительный радиус, нечисловые значения — `INVALID_ARGUMENT`; углы хранятся в `f64`, допуск `1e-9` радиан |
| Матрицы | Плотная row-major матрица `f64` с явными строками/столбцами | Произведение, преобразование, определитель или обратная матрица | Размер ноль допустим только для копирования/произведения совместимых размерностей; обратная матрица пустой/вырожденной матрицы не существует | Несовместимые размерности — `INVALID_ARGUMENT`; сингулярная матрица — `OUT_OF_RANGE`; вычисления `f64`, допуск `1e-9` |
| Транзакции | Дескриптор объекта, ожидаемая ревизия, последовательность изменений | Новая ревизия и полный атомарный результат | Пустая транзакция не меняет ревизию | Несовпадение ревизии — `CONFLICT`; частичный результат не публикуется при любой ошибке; повторное применение с тем же ключом должно быть идемпотентным |
| Пакеты | 16-байтовый заголовок `ZSK1`: смещения 0–3 — magic, 4–5 — `abi:uint16`, 6–7 — `operation:uint16`, 8–11 — `flags:uint32`, 12–15 — `payloadBytes:uint32`; затем типизированный payload | Результат той же операции в бинарном виде | Нулевая длина допустима только для операции без параметров | Неизвестная обязательная возможность/версия — `UNSUPPORTED`; неверная длина/порядок байт — `INVALID_ARGUMENT`; размер выше лимита — `OUT_OF_RANGE` |

## Параллелизм и платформы

- Однопоточная сборка WASM — основной браузерный вариант.
- Многопоточная сборка использует WASM threads и `SharedArrayBuffer`. В браузере необходимы `crossOriginIsolated === true`, `SharedArrayBuffer`, а также изоляционные заголовки COOP `same-origin` и COEP `require-corp` (либо совместимая политика credentialless). Без этого многопоточный запуск прекращается с `UNSUPPORTED`; автоматической подмены однопоточного кода многопоточным нет.
- Нативная очередь задач сохраняет FIFO и ждёт завершения уже поставленных задач при остановке. Операции над одним буфером не выполняются параллельно с его освобождением. Подключение очереди к игровым транзакциям остаётся отдельным этапом.
- Expo Go не загружает произвольный JSI/C++ модуль приложения. Для JSI требуется собственная нативная сборка Expo. Текущий артефакт предназначен для браузера; JSI-адаптер не включён в приложение.

## Совместимость и статус реализации

Добавление функций без изменения существующих структур допускается только при сохранении ABI 1. Изменение сигнатур, численной семантики, схем дескрипторов или сериализации требует повышения ABI major. Неизвестные поля пакета игнорируются лишь при установленном необязательном флаге; неизвестные обязательные поля отклоняются.

| Проверка | Статус |
| --- | --- |
| Один исходный C++20 код → WASM и Node native addon | Автоматическая сборка из `kernel/src` |
| Минимальный вызов из Node через WASM и native addon | Проверяется `pnpm --filter @workspace/zero-strategy run kernel:test` |
| Однопоточная и pthread WASM-компиляция; нативная FIFO-очередь | Проверяются этой же командой |
| Браузерное исполнение | Смоук-страница собирается рядом с WASM; фактический прогон требует доступного Chromium |
| JSI-адаптер | Компилируется на хосте против заголовков React Native |
| Android/JSI | C ABI `.so`, JSI `.a` и smoke-программа собираются для `arm64-v8a` и `x86_64`; запуск требует подключённого Android-устройства/эмулятора и здесь не выполнялся |
| iOS/JSI | Используется тот же C++20 исходник; инструкции сборки подготовлены, но сборка и исполнение требуют Xcode на macOS и здесь не проверялись |

Сам факт сборки или передачи минимального вызова не является утверждением об ускорении игры.
