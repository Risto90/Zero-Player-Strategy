# Контракт вычислительного ядра Zero Strategy — ABI 1

## Назначение и границы

Ядро предоставляет воспроизводимые математические операции и управляет двоичной памятью. Оно не принимает игровые решения и не задаёт правила населения, карты, кистей или транзакций. Потребители передают типизированные массивы и идентификаторы; сериализация всей карты в JSON для каждого вызова запрещена.

| Потребитель | Данные игры | Граница интеграции |
| --- | --- | --- |
| `game/contours.ts` | Строки контура `{y,start,end}`, пересечения, объединение и вычитание | Интервалы целых координат; геометрические операции не разворачивают область в список пикселей |
| `game/zones.ts` | Замкнутые кольца координат вершин и скалярные зоны | Типизированные значения растра, маска включения и кольца; обход строками не блокирует интерфейс |
| `game/composition.ts` | Идентификаторы групп и доли, кратные `SHARE_STEP` | Массивы идентификаторов и весов; игровые правила округления остаются в игровом слое |
| `game/brush.ts`, `game/countryExpansionContours.ts` | Выбор и пересечение участков карты | Наборы и контуры; ограничения доступной, начальной и конечной области не смешиваются |
| `game/mapLabels.ts` | Поиск позиций на видимом контуре | Геометрические запросы и камера остаются вне универсальной алгебры |

Реализация ABI 1 включает реестр буферов, арифметику `int32`, пакетную алгебру множеств `uint32` и взвешенные совместные группы населения. Декларативный каталог запросов TypeScript включает дополнительные табличные операции; см. [`algebra-contract.md`](./algebra-contract.md).

## Общие правила вызова

- Версия ABI — `1`; несовпадение основной версии приводит к явной ошибке загрузки.
- Функции C ABI возвращают общий код `zk_error`. При ошибке выходные значения не меняются.
- `0` зарезервирован как недопустимый дескриптор. Остальные дескрипторы имеют вид `(поколение:uint32 << 32) | (слот:uint32 + 1)`.
- Дескриптор принадлежит выдавшему его экземпляру ядра. Освобождение делает его недействительным; повторное освобождение сообщает об устаревшем дескрипторе. Слот с исчерпанными поколениями выводится из оборота, поколения не переиспользуются.
- Адрес буфера действителен до `zk_buffer_release`. Нельзя освобождать или переиспользовать буфер во время обращения к его представлению. Размер буфера неизменен.
- В WASM адрес — смещение в линейной памяти, на нативной платформе — адрес процесса. После роста памяти старые `TypedArray` считаются недействительными; представление нужно получить повторно.
- Совокупный объём буферов одного экземпляра ограничен 256 МиБ; одновременно допускается не более 65 536 дескрипторов. Превышение лимита и системная нехватка памяти имеют разные коды ошибок.
- Режим выполнения считывается из скомпилированного артефакта. Однопоточная сборка не сообщает о поддержке потоков; запрос потоков для неё отклоняется.
- Пустой вход допустим, если ниже не указано иное. Пустые буферы имеют действительный дескриптор; указатель может быть нулевым при нулевой длине.
- Порядок байт пакетов — little-endian. Целые числа имеют фиксированную ширину; вещественные числа используют IEEE 754 binary32/binary64. NaN и бесконечность запрещены в геометрических и численных операциях.
- Целочисленное переполнение возвращает `OVERFLOW`, без насыщения и циклического перехода. Для воспроизводимости запрещены `fast-math` и неявное изменение порядка суммирования.
- Для сравнения вещественных результатов используется абсолютный допуск `1e-9` и относительный допуск `1e-9 × max(|a|,|b|)`, если операция не задаёт более строгую точность.
- Сортировка равных ключей стабильна; при равных остатках или расстояниях используется возрастающий числовой идентификатор. Игровое квантование не переносится в ядро без отдельного контракта.

## Коды ошибок

| Код | Имя | Значение |
| ---: | --- | --- |
| 0 | `OK` | Операция завершена |
| 1 | `INVALID_ARGUMENT` | Нулевой обязательный указатель, неизвестный тип или недопустимое значение |
| 2 | `OUT_OF_MEMORY` | Не удалось выделить память или достигнут совокупный лимит |
| 3 | `INVALID_HANDLE` | Нулевой или структурно недопустимый дескриптор |
| 4 | `STALE_HANDLE` | Дескриптор освобождён или его поколение не совпало |
| 5 | `TYPE_MISMATCH` | Тип дескриптора не поддерживается операцией |
| 6 | `OUT_OF_RANGE` | Диапазон, индекс, размер или координата вышли за допустимые границы |
| 7 | `OVERFLOW` | Точный результат не помещается в целевой тип |
| 8 | `UNSUPPORTED` | Запрошенный режим или возможности платформы недоступны |
| 9 | `CONFLICT` | Ожидаемая ревизия транзакции не совпала с текущей |
| 10 | `INTERNAL` | Нарушен внутренний инвариант; вызывающая сторона не должна продолжать транзакцию |

## Каталог операций и численная семантика

Все операции C ABI используют общий `zk_error`. Операции, для которых ниже не перечислен отдельный код, возвращают коды, предусмотренные для их семейства.

| Семейство | Вход | Результат | Пустые и вырожденные данные | Ошибки и точность |
| --- | --- | --- | --- | --- |
| Буферы | Тип `u8/u16/i32/u32/f32/f64/i64/u64`, число элементов `uint32` | Дескриптор поколения, длина в байтах, адрес типизированной памяти | Ноль элементов создаёт пустой действительный буфер; нулевой адрес допустим только при нулевой длине | Неизвестный тип — `INVALID_ARGUMENT`, превышение размера — `OUT_OF_RANGE`, лимита или памяти — `OUT_OF_MEMORY`, старый дескриптор — `STALE_HANDLE` |
| Множества целых C ABI | Два отсортированных по возрастанию массива `uint32` без повторов; объединение, пересечение, разность, симметрическая разность или дополнение | Новый отсортированный массив без повторов | Пустое объединение и пересечение с пустым дают пустое множество; дополнение вычисляется только относительно переданного универсума | Нарушение канонической формы — `INVALID_ARGUMENT`; недостаточная ёмкость — `OUT_OF_RANGE`; результат сравнивается точно |
| Множества TypeScript | Таблицы строк и режим `set` или `multiset` | Именованная таблица результата | Множество игнорирует повторы; мультимножество сохраняет кратность | Объединение мультимножеств берёт максимальную кратность, пересечение — минимум, разность — неотрицательный остаток |
| Взвешенные группы C ABI | Совместные ключи из четырёх `uint32` на строку и отдельная масса `f64` | Канонические ключи и масса на группу | Повторные ключи суммируются для определения меры; нулевая масса не включается; атеизм обозначается `UINT32_MAX` в поле веры | Отрицательная или не конечная масса — `INVALID_ARGUMENT`; сумма вне конечного диапазона — `OVERFLOW`; порядок результата задаёт полный ключ |
| Взвешенные меры TypeScript | Совместные атрибуты строки и отдельная конечная неотрицательная масса | Мера с сохранённым полным совместным ключом | Объединение берёт максимум масс, пересечение — минимум; разность и дополнение обрезают остаток снизу нулём | Сложение масс выполняет только явная `measureSum`; произвольное округление не применяется |
| Фильтр и разбиение | Таблица и предикат-дескриптор | Одна или две таблицы | Пустая таблица остаётся пустой | Неподдерживаемый оператор или неизвестный столбец — `INVALID_ARGUMENT` |
| Соединение и произведение | Две таблицы, ключи и проекции | Таблица пар строк | Пустой вход даёт пустой результат | Несовпадение ключей — пустое соединение; результат выше лимита — `OUT_OF_RANGE` |
| Проекция, группировка и агрегаты | Таблица, ключи группировки и список агрегатов | Таблица с указанными столбцами | Пустой вход не создаёт фиктивную группу | Неизвестный столбец или неверный дескриптор — `INVALID_ARGUMENT`; суммирование конечных мер проверяет переполнение |
| Извлечение, перенос и удаление | Мера, количество, ссылка для приоритетов и упорядоченные уровни | Выбранная часть, остаток и при переносе новая целевая мера | Извлечение ограничивается доступной массой; нулевая цель оставляет источник без изменений | Дробный остаток сохраняется; выходные данные не публикуются частично |

## Параллелизм и платформы

- Однопоточная сборка WASM — основной браузерный вариант.
- Многопоточная сборка использует WASM threads и `SharedArrayBuffer`. В браузере необходимы `crossOriginIsolated === true`, `SharedArrayBuffer` и изоляционные заголовки COOP `same-origin` и COEP `require-corp` либо совместимая политика credentialless. Без них запуск завершается с `UNSUPPORTED`; автоматического переключения между однопоточным и многопоточным кодом нет.
- Нативная очередь задач сохраняет FIFO и ждёт завершения поставленных задач при остановке. Операции над одним буфером не выполняются параллельно с его освобождением. Подключение очереди к игровым транзакциям не входит в этот контракт.
- Expo Go не загружает произвольный JSI/C++ модуль приложения. Для JSI нужна собственная нативная сборка Expo. Текущий артефакт предназначен для браузера; JSI-адаптер не включён в приложение.

## Совместимость и статус реализации

Добавление функций без изменения существующих структур допускается при сохранении ABI 1. Изменение сигнатур, численной семантики, схем дескрипторов или сериализации требует повышения основной версии ABI. Неизвестные поля пакета игнорируются только при установленном необязательном флаге; неизвестные обязательные поля отклоняются.

| Проверка | Статус |
| --- | --- |
| Общий исходный код C++20 для WASM и Node.js-модуля | Автоматическая сборка из `kernel/src` |
| Пакетная алгебра множеств и совместных мер | Проверяется через C ABI и WASM/Node.js smoke-тесты |
| Каталог составных табличных запросов TypeScript | Проверяется командой `pnpm --filter @workspace/zero-strategy run test:algebra` |
| Однопоточная и многопоточная WASM-компиляция; нативная FIFO-очередь | Проверяются командой `pnpm --filter @workspace/zero-strategy run kernel:test` |
| Исполнение в браузере | Smoke-страница собирается рядом с WASM; фактический прогон требует Chromium |
| JSI-адаптер | Компилируется на хосте с заголовками React Native |
| Android/JSI | C ABI `.so`, JSI `.a` и smoke-программа собираются для `arm64-v8a` и `x86_64`; запуск требует Android-устройство или эмулятор и здесь не выполнялся |
| iOS/JSI | Используется тот же исходный код C++20; сборка и запуск требуют Xcode на macOS и здесь не проверялись |

Сборка и минимальный smoke-тест не являются утверждением об ускорении игры.
