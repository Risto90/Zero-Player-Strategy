# Контракт алгебры множеств и населения

## Один запрос

`kernel/algebra.ts` экспортирует `runAlgebraQuery({ inputs, operations })`. Входы — именованные таблицы с уникальными столбцами и строками одинаковой ширины. Операции ссылаются на эти имена и на результаты предшествующих операций. Предикаты и агрегаты задаются дескрипторами, а не JS-функциями, поэтому обход не вызывает JS-код отдельно для каждой строки.

Каталог содержит объединение, пересечение, разность, симметрическую разность, дополнение относительно обязательного универсума, принадлежность, включение, равенство, непересечение, фильтрацию, разбиение, декартово произведение, соединение по нескольким ключам, проекцию, группировку и агрегаты `count`, `sum`, `min`, `max`, `mean`. Поля результата имеют имена; промежуточные таблицы можно передавать следующей операции.

## Семантики

- `set`: повторы не меняют принадлежность. Объединение не складывает значения.
- `multiset`: повтор строки задаёт кратность. Объединение берёт максимум кратностей, пересечение — минимум, разность обрезает `left - right` снизу нулём, симметрическая разность — модуль разности.
- `measure`: строка содержит совместный ключ признаков и отдельный конечный неотрицательный столбец массы. Операции над мерами требуют полного ключа и сохраняют все измерения. Для одинаковых ключей объединение берёт большую массу, пересечение — меньшую, разность и дополнение обрезают остаток снизу нулём, симметрическая разность берёт модуль разности. Нулевые массы не включаются в результат.
- `measureSum` — единственная операция сложения мер. Повторные ключи суммируются только по явно заданным ключевым столбцам; это также явная проекция/группировка, поэтому ею нельзя незаметно заменить объединение.
- `take`, `remove`, `transfer` обрабатывают приоритетные уровни по порядку. Внутри уровня масса делится пропорционально, равные группы упорядочены ключом. `choose` выбирает по массе с воспроизводимым `uint32` seed и тем же порядком приоритетов. Остатки остаются дробными, округления до населения не выполняются.

Значения признаков включают `null`; для населения это позволяет хранить атеистов как отдельную совместную группу, не смешивая их с верующими. Культура, вера, происхождение и принадлежность хранятся в одной строке, поэтому независимые проценты не перемножаются с вымышленными корреляциями. Массы вычисляются в `f64`, сортируются перед компенсированным суммированием; нечисловые значения и переполнение отклоняются.

## C ABI и WASM

В C ABI добавлены пакетные операции над отсортированными уникальными множествами `uint32` и над совместными группами населения. `zk_measure_binary` использует четыре ключа на группу (культура, вера, происхождение, принадлежность), `UINT32_MAX` обозначает атеизм. Повторные ключи входных строк суммируются для получения массы меры. Результаты групп возвращаются в порядке полного ключа.

`createWasmKernel` предоставляет `setAlgebra`, `measureAlgebra` и `sumPopulationMeasure`. Вызов копирует типизированные входы в память ядра, выполняет всю операцию одним вызовом и возвращает новые массивы; невалидные дескрипторы и недостаточная ёмкость не публикуют частичный результат. Однопоточная и многопоточная WASM-сборки используют один и тот же исходный алгоритм.

## Проверки

`pnpm --filter @workspace/zero-strategy run test:algebra` запускает независимый эталон, законы множеств, случайные сравнения, сохранение каждой совместной группы и общей массы, ошибки входов и замер полного JS-вызова пакетного запроса.

`pnpm --filter @workspace/zero-strategy run kernel:test` собирает WASM и нативное ядро, затем проверяет WASM-обвязку, повторы ключей, дробную массу, атеистов, точность дополнения и обработку некорректных входов.
